# Day 7 · 第一周复习与自测：大模型基础概念巩固

对 Day 1 ~ Day 6 六天学习内容进行系统回顾与自测，目标是 **流畅回答 70% 以上** 的核心问题，定位知识盲区并安排针对性复习，为进入第二周做准备。

## 环境依赖

本日为 **复习 + 自测**，不强制依赖 API。若想用真实调用验证第 ④ 题（API 成本计算），可与 day1~day6 共用根目录 `.env`：

```
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-v4-flash
```

依赖：`openai`、`python-dotenv`（day1 已安装）；自测脚本本身 **无需任何外部依赖**。

## 文件

| 文件 | 内容 | 验收方式 |
|---|---|---|
| `notes_review.md` | 第一周知识图谱、易混淆点、5 道自测题详解、评分与行动指南 | 通读 + 对照自测 |
| `week1_selftest.py` | API 成本计算器 + 交互式自测问答（共 5 题，满分 25） | 运行脚本自测 |
| `results/selftest_report.md` | 运行后自动生成的自测报告（含得分、卡壳点） | 打开文件检查 |

## 运行

```bash
cd c:\MachineLearning\LLM\Demo
python day7\week1_selftest.py
```

## 验收标准

| 维度 | 达标线 | 验证方式 |
|---|---|---|
| 知识掌握 | ≥ 18 / 25 (72%) | 自测评分 |
| 流畅度 | 每题回答 ≤ 60 秒无长时间卡顿 | 计时自测 |
| 深度 | 每题至少命中 3 个关键要点 | 对照 key_points |
| 应用 | 能正确计算给定场景的 API 成本 | 成本计算器验证 |
| 查漏 | 卡壳题目已标记并安排复习 | 复习指引表填写 |

## 行动决策

- **总分 ≥ 18 (72%)** → ✅ 通过！进入第二周（个别 <3 分题目针对性复习）
- **总分 14-17 (56-68%)** → ⚠️ 部分通过，重学所有 <3 分题目后重新自测
- **总分 < 14 (<56%)** → ❌ 未通过，系统重学 Day1-Day6，3 天后重试

## 复习心态

自测的目的不是"证明自己都会"，而是 **"精准定位不会的地方"**。卡壳是好事情——它告诉你下一步该学什么。70% 通过率意味着允许 30% 的知识盲区，这些盲区正是第二周之前需要填补的。
