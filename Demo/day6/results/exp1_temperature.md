## 总结规律

| Temperature | 表现 | 适用场景 |
|-------------|------|----------|
| 0 | 完全确定性，每次输出相同 | 代码生成、事实问答、数据提取 |
| 0.7 | 适度随机，有创意但不离谱 | 写作、对话、通用任务 |
| 1.5 | 高度随机，可能出现不通顺 | 头脑风暴、创意激发 |

**核心公式**: `P(token_i) = softmax(logit_i / T)`
- T↓ -> 分布尖锐 -> 确定性↑
- T↑ -> 分布平坦 -> 随机性↑ -> 多样性↑
